# Glosarium

> Status: Draft
> Terakhir diperbarui: 2026-10-14
> Pemilik: satset-dev

| Istilah | Definisi |
|---|---|
| ANTRE_PANJANG | Status SPBU dengan antrean kendaraan panjang |
| BBM | Bahan Bakar Minyak |
| Confidence score | Nilai 1–100 yang menyatakan keyakinan sebuah status |
| Crowdsourcing | Pengumpulan laporan dari warga |
| Dishub | Dinas Perhubungan |
| Geofencing | Pembatasan berdasarkan jarak GPS dari titik tertentu (radius 100 m dari SPBU) |
| KOSONG | Status SPBU yang BBM-nya habis |
| NORMAL | Status SPBU yang beroperasi tanpa antrean berarti |
| Neon | Platform PostgreSQL serverless yang dipakai proyek ini (database, Auth, Storage) |
| Pooler | Koneksi database lewat PgBouncer (host berakhiran `-pooler`) |
| SSE | Server-Sent Events, aliran satu arah server → browser |
| Sensor fusion | Penggabungan beberapa sumber data untuk meningkatkan akurasi |
| SPBU | Stasiun Pengisian Bahan Bakar Umum |
| YOLO | Model deteksi objek untuk menghitung kendaraan |
